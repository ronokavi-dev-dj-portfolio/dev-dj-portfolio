# Content Checklist — What Ron Needs to Gather

Nothing gets built well without real content first. Fill this in (even roughly) before or
during the build — it saves a lot of back-and-forth later.

## 1. About / Bio
- [ ] Short tagline (one line, e.g. "Software Developer by day, DJ by passion")
- [ ] Short bio (2-3 sentences, for the Hero section)
- [ ] Long bio (1-2 paragraphs, for the About section) — the story: how the dev background
      led into DJing, what "2.5 years, all genres" journey has looked like, what drives you
- [ ] Personal photo (professional-looking headshot or a great DJ-booth action shot)

## 2. Services / Genres
- [ ] List of genres you play (be specific: house, hip-hop, 90s, mizrahit, whatever applies)
- [ ] Types of events you do (weddings, birthdays, corporate, bar mitzvahs, clubs, etc.)
- [ ] What makes you different (e.g. "I bring an engineer's precision to reading the room
      and running flawless tech setups")

## 3. Gallery (~20-40 photos)
- [ ] Photos from actual gigs (crowd shots, you at the decks, event setups)
- [ ] Roughly square or 4:3/16:9 crops preferred for a clean grid
- [ ] Compressed/reasonable file size (a phone photo is usually fine after basic compression —
      we'll handle optimization during the build)

## 4. Videos
- [ ] Links to YouTube/Instagram videos you want embedded (mix samples, event highlights)
- [ ] If they don't exist yet on YouTube/Instagram, they need to be uploaded there first —
      the website will only embed, not host, video

## 5. Testimonials
For each testimonial, ideally:
- [ ] Client name (first name + last initial is fine for privacy, or full name if they're ok
      with it)
- [ ] Event type (e.g. "Wedding, June 2025")
- [ ] The quote itself
- [ ] (Optional) a photo from that event

Aim for at least 3-5 to start — more can be added anytime by editing one data file.

## 6. Contact & socials
- [ ] Preferred contact method to receive form submissions (email address, WhatsApp number)
- [ ] Instagram handle / link
- [ ] Facebook page (if any)
- [ ] Any other socials (TikTok, SoundCloud, Mixcloud, etc.)

## 7. Branding (optional but nice)
- [ ] A color you'd like as the accent (or we can propose one)
- [ ] Any logo, or should we design a simple text-based logo/wordmark
